# TuturunRav

Página web para pegar un enlace de video, detectar servicios compatibles y abrir/copiar/compartir el enlace para usarlo en Rave.

## Publicación
El sitio se publica desde la rama `main` mediante GitHub Actions y GitHub Pages.

## Límites
La página reconoce enlaces de YouTube, Vimeo, Twitch y archivos directos de video cuando el formato de URL es compatible. Las vistas previas dependen de que el servicio permita incrustarlas. No hay una integración oficial con Rave en este proyecto, así que no puede añadir videos automáticamente a una sala ni controlar la aplicación.
